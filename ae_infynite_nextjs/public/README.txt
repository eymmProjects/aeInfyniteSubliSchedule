AE INFINITE PRINTING — ORGANIZED ORDER SCHEDULE

FILES
- index.html: page structure and interface elements
- styles.css: all visual styles, layout, responsive rules, and black input text
- app.js: application logic separated into named function groups

HOW TO RUN
Keep all three files in the same folder, then open index.html in a browser.
For online API saving, host the files on your configured Vercel project and make sure /api/data is deployed with the required environment variables.

FUNCTION GROUPS IN app.js
1. App configuration and shared state
2. Password/access handling
3. Loading monthly data
4. Saving monthly data
5. Safe text rendering
6. Calendar rendering and input events
7. Status legend
8. Order table rendering and editing
9. Navigation, backup, print, and initialization
